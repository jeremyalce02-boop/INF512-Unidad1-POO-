# INF512-Unidad1-POO-
Este es mi proyecto para el foro de la unidad 1 que consiste en mi aprendizaje sobre la programación orientada a objetos. 

## Descripción

En la Programación Orientada a Objetos (POO), una clase funciona como el plano de diseño de un vehículo: una plantilla abstracta que define las características y funciones que tendrá la estructura. Por su parte, el objeto es el auto físico construido a partir de ese codigo e interactuando en el mundo real.

Este objeto posee dos dimensiones fundamentales:

Estado: Corresponde a los datos o condiciones específicas de un vehículo en un instante determinado, que pudiese ser como la velocidad actual, el nivel de combustible o si el motor está encendido o apagado.

Comportamiento: Representa las acciones que el objeto puede ejecutar o recibir para alterar su estado, como acelerar, frenar o girar la llave en el encendido.



## Cómo ejecutar este proyecto

 Asegúrate de tener instalado el SDK de .NET.
